# Método Stark (opcional)

**Ative somente se o usuário pedir** ("use o Método Stark"). Fonte completa: `gestao-trafego/data/thresholds-stark.md` e `gestao-trafego/README.md`. Leia esses arquivos antes de aplicar; este resumo pode estar defasado.

Regras principais (conferir na fonte):
- Métricas por funil: TOFU → custo por seguidor (CpS) ≤ R$ 1,50 · MOFU → CTR ≥ 1,5% · BOFU → CPL R$ 7–12.
- Dado mínimo para decidir: gasto ≥ 2× CPL meta e ≥ 3 dias.
- Escala máxima 20–30% a cada 72h.
- Frequência > 3,0 = fadiga; CTR < 0,8% = candidato a pausa; criativo com > 80% da verba = dominante.
- BOFU: 30% teste / 70% escala.
- Proibições do método: sem Advantage+, sem posicionamento automático, idade 25–55, "corpo ou face, nunca ambos".

Aviso: as proibições são do método, não verdades gerais. Se a conta hoje usa Advantage+ ou outras faixas etárias por decisão do gestor, aponte a divergência como informação, não como erro, salvo se o usuário adotar o método como padrão.
